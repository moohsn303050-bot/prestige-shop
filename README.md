# برستيج — متجر برستيج

متجر إلكتروني لبيع عطور، إكسسورات، ومكياج.  
هذا المستودع يحتوي على ملفات توضيحية وبداية مشروع (بدون كود تشغيل)، مناسبة كبداية لترتيب الفكرة والتخطيط للفريق أو لمطور يتولى التنفيذ لاحقًا.

محتويات المستودع:
- README.md — هذا الملف (شرح المشروع).
- .gitignore — إعدادات تجاهل ملفات Node.
- docs/project-overview.md — ملخص المشروع والمتطلبات.
- assets/logo.svg — شعار نصي بسيط باسم "برستيج".
- translations/ar.json — ملف ترجمة بالعربية.
- issues/mvp-issues.md — قائمة مهام (Issues) جاهزة للـ MVP.

هدف هذا المستودع:
- تجهيز ملخص واضح للمشروع وملفات بداية تساعدك تبدأ بسرعة أو تسلّمها لمطور.
- إبقاء كل المحتويات باللغة العربية لتسهيل المتابعة.

كيف تبدأ:
1. افتح المستودع على GitHub.
2. أضف الملفات الموجودة هنا (إنشاء ملف جديد أو رفع ملفات).
3. بعد رفع الملفات يمكنك مشاركة الرابط مع مطور أو تبدأ التنفيذ.
