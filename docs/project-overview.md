# ملخص المشروع — متجر برستيج

الاسم المقترح: برستيج

الهدف:
متجر إلكتروني لبيع العطور، الإكسسورات، والمكياج، باللغة العربية، بسيط وسهل الاستخدام على الموبايل والويب.

الفئات الأساسية:
- عطور
- إكسسورات (سلاسل، أساور، خواتم)
- مكياج

الميزات الأساسية للإصدار الأول (MVP):
1. صفحة رئيسية تعرض منتجات مميزة.
2. صفحة تصفح المنتجات + بحث + فلتر بسيط.
3. صفحة منتج بها صور وسعر ووصف وزر إضافة للسلة.
4. سلة مشتريات ونموذج طلب بسيط (طريقة الدفع: الدفع عند الاستلام).
5. تسجيل/تسجيل دخول مستخدم (بالبريد أو رقم الموبايل).
6. زر واتساب للأعمال للتواصل السريع.
7. دردشة داخل التطبيق (محادثة بسيطة بين المس��خدم والإدارة).
8. نظام نقاط ولاء بسيط (اجمع نقاط لكل عملية شراء واستبدلها بخصم).
9. لوحة إدارة بسيطة لإضافة المنتجات ومتابعة الطلبات.
10. واجهة عربية RTL.

التقنية المقترحة (مجانية قدر الإمكان):
- واجهة: موقع يعمل على الويب والموبايل (صفحة PWA أو صفحة ثابتة كبداية).
- خدمات تسجيل وبيانات: Firebase.
- استضافة: Vercel أو Netlify.
- دردشة: Firebase أو زر واتساب + دردشة داخلية بسيطة.
- الدفع: ابدأ بـ "الدفع عند الاستلام".

المطلوب منك كبائع:
- صور منتجات بجودة جيدة.
- عناوين وأسعار ووصف باللهجة اللي تفضلها.
- سياسة الخصوصية وسياسة الإرجاع ومعلومات التواصل.

خطوات مقترحة للبدء:
1. تجهيز قائمة المنتجات (Excel أو CSV).
2. تجهيز صور الشعار والهوية.
3. رفع ملفات البداية للمستودع.
4. تنفيذ الصفحات الأساسية.
5. اختبار وجمع ملاحظات.
6. تحسين وتجهيز للنشر.
